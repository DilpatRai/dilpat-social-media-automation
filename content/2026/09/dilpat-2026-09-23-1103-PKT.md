## Instagram Caption

Database indexes are one of the simplest ways to improve query performance—when they match the way your application reads data.

An index helps the database find matching rows without scanning the entire table.

A practical checklist:

• Index columns used in frequent WHERE clauses
• Review columns used for JOIN and ORDER BY operations
• Use composite indexes when the query filters on multiple columns
• Remove indexes that add write cost without helping real queries
• Measure with an execution plan instead of guessing

The goal is not to index every column. The goal is to support the queries that matter.

## Facebook Caption

A database index is a separate data structure that helps the database locate rows faster.

Without a useful index, the database may need to scan many rows. With the right index, it can often narrow the search much earlier.

Good indexing decisions usually come from real query patterns:

- Columns used in WHERE clauses
- Columns used in JOIN conditions
- Columns used for sorting or filtering
- Composite indexes for common multi-column queries

Indexes also have a cost: they consume storage and can slow INSERT, UPDATE, and DELETE operations. That is why indexing should be guided by execution plans and measured workload—not assumptions.

## LinkedIn Caption

Database performance is often a query-design problem before it becomes a hardware problem.

Indexes can reduce the amount of data a database must inspect, but only when they align with the access patterns of the application.

A useful way to reason about indexing:

• Start with the slow query and its execution plan
• Identify predicates, joins, and sort operations
• Choose a single-column or composite index that supports the real access path
• Re-check selectivity and write overhead
• Remove indexes that do not improve important workloads

An index is not automatically beneficial. It is a trade-off between faster reads, extra storage, and additional maintenance during writes.

The engineering goal is targeted indexing based on evidence.
